HOW IT DECIDES

Rules first. Models second. Abstain by default.
01 · RULES

Deterministic where it can be

Age, sex, ECOG and simple lab thresholds are decided by rules. Same input, same finding, every time.

02 · JUDGES

Models must quote a fact

Optional judges decide the remaining criteria only when they cite a verbatim patient fact line. Run them on synthetic or consented data only.
